# Proyectos de Power Automate

Esta sección reúne automatizaciones, flujos en la nube e integraciones desarrolladas con Microsoft Power Automate.

## Proyectos documentados

- [Automatización de SharePoint y Excel](SharePoint-Excel-Automation/README.md): arquitectura, flujos FL01-FL05, Office Scripts y documentación de SharePoint.
- [Índice de documentación técnica](SharePoint-Excel-Automation/docs/README.md).
- [Avisos de caducidad de servicios](Service-Expiration-Alerts/README.md): flujo programado probado, diagrama Mermaid en castellano y JSON anonimizado de referencia.

Los flujos del proyecto SharePoint y Excel son demostraciones conceptuales; el JSON de Avisos de caducidad procede de un flujo original probado y está anonimizado. Ninguno de estos JSON constituye por sí solo una solución completa importable.
